## 3. Procédure de test pour le propriétaire

1. Lancer `build/package/Windows/monke_island.exe` (garder tout le dossier `Windows`).
2. Solo : JOUER > SOLO. Jouer un jour : explorer, récolter, regagner le galion, lire l'écran de fin de jour. Essayer E (inventaire), F (ramasser, marchand), G (lâcher).
3. À deux sur la même machine : lancer deux exe (fenêtrés). Le premier : JOUER > CRÉER UNE PARTIE. Le second : JOUER > REJOINDRE, adresse `127.0.0.1` (port 7777). Vérifier que le client voit l'hôte, le butin et l'écran de fin de jour.
4. Console (touche `²` ou `~`) :
   - `monke.Run.Status` : zone, jour, quota, trésorerie ;
   - `monke.Run.Money 1000` : ajoute de l'argent (pour la boutique) ;
   - `monke.Run.Stay` : tenter un jour de plus (cupidité) ;
   - `monke.Run.Leave` : quitter la région (contrat terminé) ;
   - `monke.Run.New` : nouvelle partie, remise à zéro.
